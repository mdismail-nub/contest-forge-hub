# CodeForge Landing

You are a senior full-stack web developer and UI/UX designer specializing in modern SaaS and developer community platforms. Your task is to design and implement a high-converting, responsive, single-page landing page for Competitive Coders using React, Tailwind CSS, and Lucide React icons.

Core Objectives

Build a visually striking landing page that drives developer user acquisition, contest participation, and community growth. The output must deliver production-ready code with clean component abstraction, high-contrast typography, and fully responsive layouts across all screen sizes.

Technical & Design Requirements

1. Brand Color System

 * Primary Dark/Accent: #0E131F (deep navy/charcoal for dark elements, primary text, and high-contrast containers)

 * Accent Highlight: #0066FF / #1B64F2 (electric blue for active states, CTAs, code brackets, and interactive elements)

 * Light Canvas: #FAFAFC / #FFFFFF (clean neutral background)

 * Surface/Borders: #F1F5F9 with subtle glassmorphism (backdrop-blur-md, soft ambient shadows, rounded-2xl borders)

2. Typography & Aesthetics

 * Pair a crisp geometric sans-serif for UI/body text with stylized editorial serif typography for headline accents.

 * Incorporate soft ambient glow effects, hover transitions, floating badge components, and high-contrast spatial visual hierarchy.

3. Required Section Architecture

 * Header Navigation: Sticky glassmorphic bar featuring brand logo/title, navigation links (Community, Contests, Resources, Leaderboard), dark mode toggle interface, and an Electric Blue "Join Community" CTA button.

 * Hero Section: High-impact value proposition headline with highlighted keywords, subheadline, dual action buttons ("Join Community" primary and "Explore Contests" secondary), and an interactive dynamic visual element (e.g., dynamic contest countdown widget or live leaderboard preview card).

 * Platform Trust Bar: Horizontal grid/marquee showcasing integrated platform ecosystems (Codeforces, LeetCode, CodeChef, GitHub) using soft rounded badge containers.

 * Feature Grid: 3-column feature layout detailing Weekly/Monthly Contests, Curated Resources, and Peer Mentorship with interactive hover effects and iconography.

 * Upcoming Contests / Dashboard Section: Styled UI cards displaying active contest metrics, countdown timers, participant avatar stacks, and entry action triggers.

 * CTA Footer: Deep #0E131F navy container with vibrant electric blue highlights, compelling closing headline, primary onboarding CTA, social links, and footer navigation.

Success Criteria

 * Code Quality: Modern, accessible, fully componentized React implementation using Tailwind CSS utility classes without external layout bugs.

 * UX/UI Standard: Polished aesthetic matching modern developer tools (e.g., Vercel, Linear, Stripe) that balances high conversion metrics with developer appeal.

 * Completeness: Provides fully functional code for all requested sections with realistic mock state, without placeholders or omitted components.
